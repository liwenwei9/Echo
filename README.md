# 回声 Echo

面向年轻职场人的本地轻社交平台原型。核心原则：

> 只展示附近讨论，不展示附近的人。

## 运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。

## 已实现

- 手机号与微信演示登录、退出登录
- 声场、发现、订阅三类信息流
- 内容质量与本地相关性排序
- 问一下、聊一聊、约一下三种内容
- 图文内容发布，最多 9 张图片
- 图片本地缩放、压缩和 EXIF 元数据清理
- 图片预览、排序编号与单张删除
- 内容发布与本地持久化
- 搜索与内容类型筛选
- 赞同、感谢及取消操作
- 普通回应与完整讨论页
- 换位理解式结构化异议
- 收藏、隐藏、举报
- 活动报名与退出
- 自有问题标记已解决
- 地点、话题和活动声场探索与订阅
- 通知中心与已读状态
- 个人主页与资料编辑
- 位置范围、一次验证及纯线上模式
- 每日一声、声场温度和位置安全提示
- 响应式桌面与移动端界面
- PWA Manifest

演示数据保存在浏览器 `localStorage`。当前实现用于验证完整产品流程，生产环境需要将状态层替换为认证服务、FastAPI API 和 PostgreSQL/PostGIS。

# 回声 Echo

面向年轻职场人的本地轻社交平台原型。核心原则：

> 只展示附近讨论，不展示附近的人。

## 环境要求

- Node.js 20 或更高版本
- npm 10 或更高版本
- Chrome、Edge、Safari 等现代浏览器

## 安装与运行

克隆仓库：

```bash
git clone https://github.com/liwenwei9/Echo.git
cd Echo
```

安装依赖并启动开发服务器：

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:3000
```

如需让同一局域网内的手机访问：

```bash
npm run dev -- --hostname 0.0.0.0
```

然后在手机浏览器打开电脑的局域网 IP，例如
`http://192.168.1.10:3000`。

## 怎么使用

### 1. 登录

首次打开会显示登录页面。

- **微信快捷登录**：直接进入演示账号，不会调用真实微信授权。
- **手机号登录**：输入 11 位手机号及任意 4 位以上数字验证码。
- 手机号和验证码仅用于前端交互演示，不会发送到服务器。

### 2. 浏览内容

首页包含三个信息流：

- **声场**：优先展示当前区域内具有本地价值的内容。
- **发现**：探索其他区域和话题的优质内容。
- **订阅**：只展示已订阅声场和话题的内容。

点击帖子正文或“回应”，可以展开最有帮助的回复；点击“查看全部”
进入完整讨论。

右上角搜索支持查找标题、正文、话题、区域和作者。筛选按钮可以只查看
“问一下”“聊一聊”或“约一下”。

### 3. 发出回声

点击左侧 **发出回声**，或移动端底部中央的 `+`：

1. 选择内容类型：
   - **问一下**：提出一个希望获得具体答案的问题。
   - **聊一聊**：分享观点或发起讨论。
   - **约一下**：发起公开场所的小型活动。
2. 填写标题。
3. 添加正文，或者直接添加图片。
4. 可添加最多 9 张 JPG、PNG、WebP 或 HEIC 图片。
5. 选择公开范围和话题。
6. 点击 **发布**。

图片会在浏览器中缩放、压缩并重新编码，以清除 EXIF
位置等原始元数据。图片可在发布前单张删除。

### 4. 参与讨论

每条内容支持：

- **赞同**：认同主要观点，再次点击可取消。
- **感谢**：内容对自己有帮助，再次点击可取消。
- **回应**：发表公开回复。
- **提出异议**：先复述自己理解的原观点，再选择事实、推理、价值判断或
  个人经验方面的分歧。

完整讨论页中可以查看全部回应，并标记某条回应“有帮助”。

### 5. 收藏与内容管理

点击帖子右上角的 `...`：

- 收藏或取消收藏
- 隐藏不感兴趣的内容
- 提交举报
- 自己发布的提问可以标记为“已解决”或重新打开

收藏内容只在 **我的收藏** 中展示，不会形成公开收藏数。

### 6. 探索与订阅声场

进入 **探索声场**，可以浏览：

- 地点声场
- 话题声场
- 活动声场

点击“订阅”后，相关内容会进入首页的 **订阅** 信息流。

### 7. 活动报名

“约一下”类型的帖子会显示活动人数和剩余位置。点击“报名参加”即可加入，
再次点击可以退出。当前版本仅模拟报名状态，不会创建真实群聊。

### 8. 位置隐私

点击顶部的位置按钮，可以选择：

- **仅验证一次**：加入声场时验证一次区域。
- **使用期间**：打开应用时更新区域。
- **纯线上模式**：关闭附近声场，只使用发现和订阅。

公开页面只展示 `500m内`、`3km内` 或 `同城`，不会展示坐标、精确距离、
实时位置和移动轨迹。

### 9. 通知与个人主页

- **通知**：查看回应、感谢、声场摘要和位置安全信息。
- **个人主页**：查看自己发布的内容、回应、收藏和订阅统计。
- 点击“编辑资料”可以修改公开昵称和简介。
- 页面底部可以退出演示账号。

## 数据保存与重置

当前版本没有后端，账号、帖子、图片、互动和设置均保存在浏览器
`localStorage`。

这意味着：

- 数据只在当前浏览器和当前设备中可见。
- 清理浏览器站点数据后，内容会恢复为初始演示状态。
- 不同浏览器或设备之间不会同步。
- 浏览器存储空间有限，不适合长期保存大量图片。

重置演示数据的方法：

1. 打开浏览器开发者工具。
2. 进入 Application 或“应用”面板。
3. 找到 Local Storage。
4. 删除 `http://localhost:3000` 下以 `echo-mvp-v2-` 开头的数据。
5. 刷新页面。
